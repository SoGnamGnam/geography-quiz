# Third-party data and assets

World Quiz uses the following third-party data and assets. Each keeps its own license.

## Data sources

| Source | Used for | License |
| --- | --- | --- |
| [Wikidata](https://www.wikidata.org/) | Entity data: names, capitals, leaders, populations, areas, borders… | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| [Natural Earth](https://www.naturalearthdata.com/) (v5.1.2, 1:10m admin-0 countries and map units) | Country borders, used to generate the silhouettes in `public/silhouettes/` | Public domain |

## Bundled packages

| Package | Used for | License |
| --- | --- | --- |
| [Inter](https://rsms.me/inter/) via [`@fontsource-variable/inter`](https://fontsource.org/fonts/inter) | UI font | [SIL Open Font License 1.1](https://openfontlicense.org/) |
| [`flag-icons`](https://github.com/lipis/flag-icons) | Country flags | MIT |

Build-time and development dependencies, which are not shipped in the app, are listed in `package.json`.

## Wikimedia Commons images

Coats of arms (and, later, region flags) come from [Wikimedia Commons](https://commons.wikimedia.org/). The license varies per file. The data pipeline regenerates the table below from `data/attributions/coats-of-arms.json`, so do not edit it by hand. Images are shown resized.
