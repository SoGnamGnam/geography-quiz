# Third-party data and assets

World Quiz uses the following third-party data and assets. Each keeps its own license.

## Data sources

| Source                                             | Used for                                                            | License                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------- |
| [Wikidata](https://www.wikidata.org/)              | Entity data: names, capitals, leaders, populations, areas, borders… | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| [Natural Earth](https://www.naturalearthdata.com/) | Country borders, used to generate silhouettes _(planned)_           | Public domain                                                 |
